j.web — One-page redesign

Publish the contents of this folder to the root of your GitHub Pages repository.
The new homepage is index.html. It uses the existing travel photographs and favicon, with a single About section and Instagram link.

Features:
- One-page navigation (Home / Photos / About & Instagram)
- Photo explorer grouped by region, then country
- Combined About and Instagram section; YouTube link removed
- Click-to-open photo lightbox with previous/next controls and keyboard arrows
- Responsive mobile navigation
- Accessible buttons and reduced-motion support

The original photos.html and links.html are retained in the folder as a backup, but the new homepage does not link to them.
